# Wisdom Bytes survey: single-page questionnaire on GitHub Pages
- Audience: older people new to AI. Keep wording plain and warm, with large, clear controls.
- Everything is in index.html (32KB): grep the question number (q1–q20) rather than reading whole.
- No build step, no tests. Check changes by loading the page in Playwright.
- Answer directly. Don't restate your reasoning in the reply.
- Read TASKS.md at the start of a session and keep it current (rule inside).
